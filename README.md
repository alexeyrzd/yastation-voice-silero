# yastation-voice

Как заставить Яндекс Станцию говорить **твоим клонированным голосом** (Silero) вместо
голоса Алисы.

Важно понимать сразу: это **не** «воткнуть голос в приложение Алиса» — Алиса облачная и
закрытая, подменить её озвучку изнутри официального сервиса нельзя. Рабочий путь —
полностью заменить облачный бэкенд колонки своим локальным (ASR + LLM + TTS), и тогда
TTS-часть этого бэкенда можно сделать любой, в том числе Silero-клоном.

```
Станция ──(DNS Яндекса → твой ПК)──> quasard (ASR, LLM, протокол колонки)
                                         │  TTS engine = "openai"
                                         ▼
                              POST http://127.0.0.1:8501/audio/speech
                                         │
                                  silero_tts_server.py (этот репо)
                                         │  clone_voice.py (silero-clone-lite)
                                         ▼
                                 WAV твоим голосом → quasard → колонка (Ogg/Opus)
```

## Что для этого нужно (все три вещи обязательны)

1. **Рутованная Яндекс Станция с постоянным SSH-доступом.**
   Подойдёт любой публичный способ рутования (эксплойт через подмену DNS/прошивки,
   установка Entware + dropbear, постоянный пароль/ключ root). Готовые инструменты и
   инструкции есть в открытых проектах по теме `yandex station root` — этот репозиторий
   с них не начинается и их не описывает, он стартует с того, что root уже есть.

2. **[quasard](https://github.com/amirilivice/quasard) — локальный бэкенд Алисы.**
   Этот репозиторий написан под quasard — локальный сервер, который полностью подменяет
   облако Алисы: активация колонки, распознавание речи, ответы через LLM, озвучка,
   музыка. У него уже есть универсальный TTS-движок `engine = "openai"`: шлёт текст на
   `POST {base_url}/audio/speech` и ждёт аудио-файл в ответ (формат OpenAI Audio API).
   Поставь и настрой quasard по его собственной документации — DNS-редирект доменов
   Яндекса на свой ПК, сертификат, которому доверяет колонка, и т.д.

3. **[silero-clone-lite](https://github.com/alexeyrzd/silero-clone-lite) — твой голос.**
   Отдельный репозиторий: клонирование голоса на Silero (v5_ru) по нескольким минутам
   записи. Склонируй его рядом и получи `.pt`-файл голоса по его собственному README —
   здесь этот процесс не повторяется.

4. **Этот репозиторий — мост.**
   Берёт готовый `.pt`-голос из silero-clone-lite и отдаёт его тем же протоколом, что
   ждёт quasard, через `/audio/speech`. В сам quasard ничего менять не нужно —
   достаточно поменять одну строчку в его конфиге (см. ниже).

## Установка

```bash
git clone https://github.com/alexeyrzd/silero-clone-lite ../silero-clone-lite
pip install -r requirements.txt
```

Голос делается отдельно, по README репозитория `silero-clone-lite` — в итоге получится
файл вроде `voices/myvoice/myvoice_extended_dec.pt`.

## Запуск моста

```bash
python silero_tts_server.py --repo ../silero-clone-lite --voice ../silero-clone-lite/voices/myvoice/myvoice_extended_dec.pt --port 8501
```

`--repo` — путь к клону `silero-clone-lite` (по умолчанию `../silero-clone-lite`,
оттуда же по умолчанию берётся модель `v5_ru.pt`, если не передан `--model`).

В конфиге quasard (`config.toml`):

```toml
[tts]
engine = "openai"
base_url = "http://127.0.0.1:8501"
voice = "myvoice"      # сервер это поле игнорирует, голос фиксирован через --voice
api_key = "any"         # сервер не проверяет ключ
```

Дальше запускается сам quasard — и Алиса на колонке отвечает твоим голосом. Чтобы
сменить голос, достаточно перезапустить `silero_tts_server.py` с другим `--voice`.

## Ограничения и честно про качество

- Это не студийный клон: интонация и длительности остаются «силеровскими», на незнакомых
  фразах может плыть сильнее, чем на коротких типовых. Подробности — в README
  `silero-clone-lite`.
- Нужна видеокарта с CUDA для приемлемой скорости синтеза в реальном времени; на CPU
  всё работает, но заметно медленнее.

  реальному человеку, не являющемуся тобой.

## Структура

```
silero_tts_server.py    сервер с /audio/speech для quasard (движок "openai")
voices/                 сюда можно класть свои готовые .pt-файлы голосов
requirements.txt        зависимости (torch, librosa, soundfile, fastapi, uvicorn)
```
